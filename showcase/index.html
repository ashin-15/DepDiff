GOOD TO KNOW

A little more context.

Does this replace npm audit or Dependabot?+

No. Those tools help with known advisories and dependency updates. depdiff complements them with a version-to-version view of statically visible capabilities and metadata.

Is the website running a live package analysis?+

No. The interactive showcase displays saved reports generated by the real CLI against synthetic fixtures. To analyze your own local versions, use the Python CLI.

Can it download any package from npm?+

Not in the current MVP. You provide local package directories under the documented fixture layout. Registry retrieval, lockfile-wide analysis, and hosted scanning are not implemented.

Does an “ok” verdict mean a package is safe?+

No. It means the configured static analysis found no new capability signal under its policy. Regex analysis can miss runtime-only behavior and obfuscation, or match comments and strings. Every verdict is a recommendation for human review.
