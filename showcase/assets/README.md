# Bundled typefaces

The showcase self-hosts Latin-subset WOFF2 files for Manrope (variable weight)
and IBM Plex Mono (regular), distributed under the SIL Open Font License 1.1.
They are presentation assets, not runtime dependencies. No font request leaves
the site at runtime.

- Manrope: https://github.com/sharanda/manrope
- IBM Plex: https://github.com/IBM/plex
- Font files sourced from the Google Fonts distribution.

License notices are preserved in `manrope-OFL.txt` and `ibm-plex-OFL.txt`.
